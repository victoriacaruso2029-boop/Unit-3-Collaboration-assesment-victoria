2. Why do developers use branches?
Developers use branchs because it is free to be modified, without making permanant changes to the original "main" branch.

3. What is git? What is github? How does git and git hub work together?
Git is a command line that helps manage our files like looking at updates/history. Github is a website where developers can save their code online. They work together because in github we use git as a command line.
